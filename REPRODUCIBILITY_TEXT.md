Code, the exact elicitation prompts, the frozen raw model outputs, the
calibration and evaluation world-id splits, and the analysis scripts
underlying every result in this section will be made publicly available.
Every reported table and figure in Sections 7 and 8 can be reproduced
from the archived, frozen model outputs without access to the Anthropic
API or any other hosted model provider. Rerunning the live elicitation
calls that generated those outputs is possible for a reader with valid
API credentials but constitutes a replication of the experiment rather
than a guaranteed exact computational reproduction, since hosted model
providers can update model weights or serving behavior behind a fixed
model identifier without notice.
